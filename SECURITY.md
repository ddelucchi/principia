# Security

This repository is research/portfolio software, not a production service or a safety-critical system.

## Reporting a vulnerability

Please do not publish credentials, exploit details, or sensitive reproduction data in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab. Otherwise, contact the repository owner through the GitHub profile and request a private disclosure channel before sending sensitive material.

A useful report includes:

- affected commit and component
- minimal reproduction steps
- expected and observed behavior
- impact assessment
- proof of concept when appropriate
- suggested mitigation, if known

## Secrets

Do not commit API keys, private keys, tokens, passwords, wallet material, or machine-local credentials. Local secrets belong in ignored configuration or environment files.

## Support boundary

There is no bug-bounty program or production response SLA. Security reports that affect the integrity of the published research/software surface are still welcome.
